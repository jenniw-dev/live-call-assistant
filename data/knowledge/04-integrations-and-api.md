# Integrations and API

## I01：What integrations do you have?

> Paid plans include Slack, Microsoft Teams, Google Calendar, Outlook Calendar, GitHub, GitLab and Zapier. Free workspaces don't have integrations.

## I02：Do you have an API?

> Yes. There's a REST API on Team, Business and Enterprise. Any member can create a personal API key in Profile, API keys. The limit is 100 requests per minute per key.

**Follow-up: Can we get a higher rate limit?**
> Enterprise customers can ask for a higher limit through their account manager. For Team or Business, the limit is fixed at 100 requests per minute.

## I03：Do you support webhooks?

> Yes, on Team and above. Admins can add webhooks in Settings, Integrations, Webhooks, for events like task created, task completed and comment added.

## I04：How do I connect Slack?

> An admin goes to Settings, Integrations, Slack and clicks Connect. After approving in Slack, each project can choose a Slack channel for its updates.

## I05：Can I import from Trello, Asana or a spreadsheet?

> Yes. There are one-click importers for Trello and Asana, and a CSV importer for spreadsheets. CSV files must be UTF-8, under 10 MB and up to 5,000 rows per import.

## I06：Do you have mobile apps?

> Yes, for iPhone and Android, free on every plan. They support tasks, comments, notifications and file uploads, but workspace settings and billing are web-only.
